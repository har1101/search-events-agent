# 目標管理エージェントアプリケーション 要件定義書

## 実現したいこと
- 自然言語で目標や期間を設定できるエージェントを作る
  - 粒度が粗い場合はユーザーへ聞き返して細かく設定してくれる
  - チャット入力と音声の両方で入力できるのが理想だが、まずはチャットのみ実装
- リマインド機能付き
  - 目標達成期間と進捗に応じてエージェントがリマインドしてくれる
  - エージェント自身がリマインドすべきスケジュールを登録してくれる
- ダッシュボード画面で目標一覧と進捗を確認できる
  - 目標の進捗度合いに関しては、エージェントが自分でQiita・GitHub・connpass・note・Xなどを確認して収集してくれる+自分でも登録できる
- AWSを使ってホスティングする
- ダッシュボード用・チャット用フロントエンドはReact+Viteを用いる
- リマインド通知にはLINEを用いる
  - LINEでもチャットでき、進捗を更新したりできる
  - ひとまずLINE側のチャットは簡易実装でOK
- 目標を設定したら、Googleカレンダーにも登録してくれる
  - Google Calendar APIを使って自前実装する必要がある
  - 詳しくは[design_calendar_tool.md](design_calendar_tool.md)参照

## 考えているアーキテクチャ図
- [architecture.png](architecture.png)を参照
- メイン機能とリマインド機能の2つが存在

### メイン機能
- ダッシュボードで目標一覧を管理
  - Goal: 「今年はアウトプット増やす」
  - Milestones: 「月2本Qiita」「月1登壇」「週3コミット」
  - Metrics: qiita_posts_count, connpass_talks_count, github_commits_count…
- チャット画面でエージェントと対話
  - 粒度が粗い時に 質問テンプレで詰める(期限、頻度、成果物、評価指標、優先度)
  - 測れない目標を測れる形に変換する提案(例：学習→記事/PR/登壇/メモ)
- エージェントがその日やるべきToDoリストも作成してくれる(MVPではない)
  - ToDoリストの達成状況を登録すると、次のToDoなども適宜修正してくれる
  - データベースの更新をトリガーに、エージェントが動いてToDoをトリガーしてくれると嬉しいが、今のところ必須ではない

### リマインダー機能
- 登録しておいたLINE経由で、ユーザーに通知を飛ばしてくれる
  - 例えば1週間の進捗を踏まえて目標までにあとどのくらいのことをすればいいのか教えてくれるなど
  - このタイミングでToDoを更新するでも良い
- 1週間の進捗はユーザーが登録することもできるし、エージェントがある程度自分から収集してくれたりもする
  - 対象がエンジニアであれば、エージェントがGitHubからコミット履歴を取ってくるとか、Qiitaからブログを取得してくるとか
  - 趣味の部分はある程度自分で登録するしか無い、ただこれも自然言語でギター○hとかできるだけ簡単にする形で
